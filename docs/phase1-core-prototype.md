# 企鹅滑冰 - 第一阶段：核心玩法原型

## 阶段目标

实现企鹅滑冰的核心物理机制和基础游戏循环，包括：
- 企鹅在冰面上的滑行物理
- 冰块推动机制
- 碰撞检测
- 基础关卡和胜利判定

## 模块说明

### 1. 游戏入口 (game.js)

**职责**：
- 初始化游戏
- 管理游戏主循环
- 处理游戏状态
- 协调各模块交互

**核心方法**：
| 方法 | 说明 |
|------|------|
| `init()` | 初始化游戏，绑定事件，加载关卡 |
| `bindEvent()` | 绑定触摸事件 |
| `loadLevel(levelNum)` | 加载指定关卡 |
| `update()` | 游戏逻辑更新 |
| `render()` | 渲染游戏画面 |
| `loop()` | 游戏主循环 |

### 2. 基础类 (js/base/)

#### Sprite (sprite.js)
精灵基类，所有游戏对象的基础。

**属性**：
| 属性 | 类型 | 说明 |
|------|------|------|
| `x` | number | X坐标 |
| `y` | number | Y坐标 |
| `width` | number | 宽度 |
| `height` | number | 高度 |
| `visible` | boolean | 是否可见 |

**方法**：
| 方法 | 说明 |
|------|------|
| `collidesWith(other)` | AABB碰撞检测 |
| `render(ctx)` | 渲染（子类重写） |
| `update()` | 更新（子类重写） |

#### Pool (pool.js)
对象池，用于复用游戏对象，减少GC压力。

**方法**：
| 方法 | 说明 |
|------|------|
| `get()` | 获取对象 |
| `release(obj)` | 回收对象 |
| `releaseAll()` | 回收所有活跃对象 |

### 3. 游戏运行时对象 (js/runtime/)

#### Penguin (penguin.js)
企鹅类，玩家控制的角色。

**物理属性**：
| 属性 | 值 | 说明 |
|------|-----|------|
| `vx`, `vy` | - | 速度分量 |
| `pushForce` | 5 | 推动力 |
| `friction` | 0.98 | 冰面摩擦系数 |

**核心方法**：
| 方法 | 说明 |
|------|------|
| `handleTouchStart(touch)` | 处理触摸开始 |
| `handleTouchMove(touch)` | 处理触摸移动 |
| `handleTouchEnd()` | 处理触摸结束，施加推力 |
| `applyForce()` | 根据方向施加推力 |
| `pushStone(stone)` | 推动冰块 |
| `update()` | 更新物理状态 |
| `render(ctx)` | 渲染企鹅（几何图形） |

**操作方式**：
1. 触摸屏幕开始
2. 滑动手指选择方向
3. 松开手指，企鹅向该方向滑行

#### Stone (stone.js)
冰块类，可被企鹅推动的物体。

**物理属性**：
| 属性 | 值 | 说明 |
|------|-----|------|
| `vx`, `vy` | - | 速度分量 |
| `friction` | 0.92 | 冰块摩擦系数（比冰面大） |

**核心方法**：
| 方法 | 说明 |
|------|------|
| `update()` | 更新物理状态 |
| `checkBoundsStop()` | 边界检测（碰到停止） |
| `render(ctx)` | 渲染冰块 |

#### Target (target.js)
目标区域类，冰块需要被推到的位置。

**核心方法**：
| 方法 | 说明 |
|------|------|
| `contains(stone)` | 检测冰块是否在目标内 |
| `update()` | 更新脉冲动画 |
| `render(ctx)` | 渲染目标区域 |

#### Background (background.js)
背景类，绘制冰面背景。

**特性**：
- 渐变冰面底色
- 随机冰面裂纹
- 闪烁冰面光点
- 调试网格线

### 4. 物理系统 (js/physics/)

#### Physics (physics.js)
物理引擎，处理冰面滑行物理效果。

**核心方法**：
| 方法 | 说明 |
|------|------|
| `applyFriction(obj, friction)` | 应用摩擦力 |
| `clampSpeed(obj, maxSpeed)` | 限制最大速度 |
| `isStopped(obj)` | 判断是否停止 |
| `updatePosition(obj)` | 更新位置 |
| `checkBounds(obj, w, h, bounce)` | 边界检测与反弹 |

#### Collision (collision.js)
碰撞检测工具函数。

**函数**：
| 函数 | 说明 |
|------|------|
| `checkAABB(a, b)` | AABB矩形碰撞检测 |
| `pointInRect(x, y, rect)` | 点是否在矩形内 |
| `getCollisionNormal(a, b)` | 计算碰撞法线 |

### 5. 关卡管理 (js/levels/)

#### LevelManager (level-manager.js)
关卡管理器，负责加载和管理关卡数据。

**核心方法**：
| 方法 | 说明 |
|------|------|
| `loadLevel(levelNum)` | 加载关卡数据 |
| `getLevel(levelNum)` | 获取关卡数据 |
| `setCurrentLevel(levelNum)` | 设置当前关卡 |
| `getNextLevel()` | 获取下一关编号 |

### 6. 关卡数据 (levels/)

关卡数据使用JSON格式存储。

**数据结构**：
```json
{
  "id": 1,
  "name": "关卡名称",
  "penguin": { "x": 50, "y": 50 },
  "stones": [
    { "x": 200, "y": 150, "size": 40 }
  ],
  "target": { "x": 300, "y": 400, "width": 50, "height": 50 },
  "par": 3
}
```

## 游戏流程

```
1. 游戏启动
   ↓
2. 加载第1关
   ↓
3. 玩家滑动屏幕选择方向
   ↓
4. 企鹅向该方向滑行
   ↓
5. 企鹅碰到冰块 → 推动冰块
   ↓
6. 冰块滑动直到停止
   ↓
7. 检测冰块是否在目标位置
   ↓
8. 所有冰块到位 → 通关成功
   ↓
9. 加载下一关
```

## 物理参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 冰面摩擦 | 0.98 | 企鹅在冰面上的摩擦系数 |
| 冰块摩擦 | 0.92 | 冰块在冰面上的摩擦系数 |
| 最大速度 | 8 | 企鹅最大滑行速度 |
| 停止阈值 | 0.1 | 速度低于此值视为停止 |
| 推动力 | 5 | 企鹅推动冰块的力量 |
| 推力传递 | 50% | 企鹅传递给冰块的推力比例 |
| 反弹系数 | 0.5 | 企鹅碰到边界的反弹系数 |

## 运行说明

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开微信开发者工具，选择"小游戏"
3. 导入项目，选择 `penguin-skating-game` 目录
4. 填写 AppID（测试可选"测试号"）
5. 点击"编译"运行

## 操作说明

- **滑动屏幕**：选择企鹅滑行方向
- **松开手指**：企鹅向该方向滑行
- **推动冰块**：将冰块推到绿色目标区域
- **通关条件**：所有冰块都在目标区域内
