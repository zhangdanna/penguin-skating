## 模块说明

### 1. 场景管理器 (scene-manager.js)

**职责**：管理游戏场景的切换和生命周期

**核心方法**：
| 方法 | 说明 |
|------|------|
| `register(name, scene)` | 注册场景 |
| `switchTo(name, data)` | 切换场景 |
| `getCurrentScene()` | 获取当前场景 |
| `update()` | 更新当前场景 |
| `render(ctx)` | 渲染当前场景 |
| `onTouchStart(touch)` | 处理触摸开始 |
| `onTouchMove(touch)` | 处理触摸移动 |
| `onTouchEnd(touch)` | 处理触摸结束 |

**场景生命周期**：
```
onEnter(data)  → 进入场景时调用
update()       → 每帧更新
render(ctx)    → 每帧渲染
onExit()       → 退出场景时调用
```

### 2. 按钮组件 (button.js)

**职责**：可点击的UI按钮

**配置项**：
| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `x` | number | 0 | X坐标 |
| `y` | number | 0 | Y坐标 |
| `width` | number | 150 | 宽度 |
| `height` | number | 50 | 高度 |
| `text` | string | '' | 按钮文字 |
| `fontSize` | number | 20 | 字体大小 |
| `textColor` | string | '#ffffff' | 文字颜色 |
| `bgColor` | string | '#4a90d9' | 背景颜色 |
| `hoverColor` | string | '#357abd' | 悬停颜色 |
| `borderColor` | string | '#2c5282' | 边框颜色 |
| `borderRadius` | number | 8 | 圆角半径 |
| `onClick` | function | null | 点击回调 |

**方法**：
| 方法 | 说明 |
|------|------|
| `contains(x, y)` | 检测点是否在按钮内 |
| `onTouchStart(touch)` | 处理触摸开始 |
| `onTouchEnd(touch)` | 处理触摸结束 |
| `render(ctx)` | 渲染按钮 |
| `setText(text)` | 设置按钮文字 |
| `setEnabled(enabled)` | 设置是否可用 |
| `setVisible(visible)` | 设置是否可见 |

### 3. 主菜单场景 (menu-scene.js)

**职责**：游戏主菜单界面

**界面元素**：
- 游戏标题（带下落动画）
- 企鹅角色（带摇摆动画）
- 雪花背景效果
- 三个按钮：开始游戏、继续游戏、设置

**按钮功能**：
| 按钮 | 功能 |
|------|------|
| 开始游戏 | 进入关卡选择界面 |
| 继续游戏 | 读取存档，继续上次关卡 |
| 设置 | 打开设置界面（待实现） |

### 4. 关卡选择场景 (level-select-scene.js)

**职责**：显示所有关卡，支持选择

**界面元素**：
- 返回按钮
- 关卡网格（4列）
- 关卡状态显示（锁定/解锁）
- 星星评价显示

**关卡状态**：
| 状态 | 视觉表现 |
|------|----------|
| 已解锁 | 蓝色背景，显示关卡编号 |
| 未解锁 | 灰色背景，显示锁定图标 |
| 已通关 | 显示星星评价 |

**数据存储**：
- `gameProgress`: 存储解锁关卡进度
- `level_{id}`: 存储每关星星评价

### 5. 游戏HUD (game-hud.js)

**职责**：游戏内信息显示

**显示内容**：
| 元素 | 位置 | 说明 |
|------|------|------|
| 关卡编号 | 左上 | 当前关卡 |
| 步数 | 左下 | 当前步数（颜色随标准变化） |
| 标准步数 | 步数右侧 | 灰色小字 |
| 时间 | 顶部中央 | 游戏用时 |
| 暂停按钮 | 右上 | 点击暂停游戏 |

**步数颜色**：
- 绿色：步数 ≤ 标准步数
- 红色：步数 > 标准步数

### 6. 暂停场景 (pause-scene.js)

**职责**：游戏暂停时的覆盖层界面

**界面元素**：
- 半透明遮罩
- "游戏暂停"标题
- 三个按钮：继续游戏、重新开始、返回菜单

**按钮功能**：
| 按钮 | 功能 |
|------|------|
| 继续游戏 | 关闭暂停，继续游戏 |
| 重新开始 | 重置当前关卡 |
| 返回菜单 | 返回主菜单 |

### 7. 结算场景 (result-scene.js)

**职责**：通关后显示结果和评价

**界面元素**：
- 半透明遮罩
- "通关成功！"标题（带缩放动画）
- 关卡编号
- 星星评价（依次出现动画）
- 步数统计
- 用时统计
- 两个按钮：下一关、重玩

**星级计算**：
| 条件 | 星级 |
|------|------|
| 步数 ≤ 标准步数 | ⭐⭐⭐ |
| 步数 ≤ 标准步数 × 1.5 | ⭐⭐ |
| 其他 | ⭐ |

## 游戏流程

```
游戏启动
  ↓
主菜单场景
  ↓
点击"开始游戏"
  ↓
关卡选择场景 ←──────┐
  ↓                 │
选择关卡            │
  ↓                 │
游戏场景            │
  ↓                 │
点击暂停按钮        │
  ↓                 │
暂停场景 ──→ 继续游戏
  ↓                 │
点击"返回菜单" ─────┘
  ↓
通关
  ↓
结算场景
  ↓
点击"下一关" → 游戏场景
点击"重玩" → 游戏场景
```

## 数据存储

### gameProgress（游戏进度）
```javascript
{
  unlockedLevel: 5,    // 已解锁最高关卡
  currentLevel: 3      // 当前关卡
}
```

### level_{id}（关卡数据）
```javascript
{
  stars: 3,            // 星星评价（1-3）
  moves: 5,            // 完成步数
  timestamp: 1234567890 // 完成时间
}
```

## 场景切换

| win | 点击"重玩" | game |
