# 企鹅滑冰 - 第六阶段：微信登录与排行榜UI

## 阶段目标

将微信登录和排行榜功能集成到游戏UI中：
- 创建登录界面场景
- 创建排行榜界面场景
- 集成微信服务到游戏主逻辑
- 通关后自动上报分数

### 3. 游戏主逻辑更新 (game.js)

#### 新增方法

| 方法 | 说明 |
|------|------|
| `initWechat()` | 初始化微信服务 |
| `reportScore()` | 上报分数到排行榜 |

#### 初始化流程

```javascript
init() {
  this.initWechat()    // 1. 初始化微信服务
  this.initAudio()     // 2. 初始化音效
  this.initUI()        // 3. 初始化UI
  this.bindEvent()     // 4. 绑定事件
  this.loop()          // 5. 开始游戏循环

  this.sceneManager.switchTo('menu')
  this.audioManager.playBGM()
}
```

#### 分数上报

通关后自动调用 `reportScore()`：

```javascript
onWin() {
  // ... 其他逻辑

  // 保存关卡进度
  this.saveLevelProgress()

  // 上报分数到排行榜
  this.reportScore()

  // 显示结算界面
  this.resultScene.setResult(...)
  this.resultScene.show()
}
```

## 数据流

### 登录流程

```
用户点击"个人中心"
    ↓
进入登录场景
    ↓
用户点击"微信登录"
    ↓
调用 wechatService.login()
    ↓
获取用户信息
    ↓
保存到本地存储
    ↓
更新UI显示
```

### 分数上报流程

```
用户通关
    ↓
调用 onWin()
    ↓
调用 saveLevelProgress()
    ↓
调用 reportScore()
    ↓
检查是否已登录
    ↓
调用 wechatService.reportScore()
    ↓
上报到微信开放数据域
```

### 排行榜显示流程

```
用户点击"排行榜"
    ↓
进入排行榜场景
    ↓
检查登录状态
    ↓
调用 loadRankData()
    ↓
通知开放数据域显示
    ↓
获取好友排行数据
    ↓
渲染排行榜UI
```

## 分数计算公式

```javascript
score = stars * 1000 - moves * 10
```

| 星级 | 基础分 | 说明 |
|------|--------|------|
| 3星 | 3000 | 步数 ≤ 标准步数 |
| 2星 | 2000 | 步数 ≤ 标准步数 × 1.5 |
| 1星 | 1000 | 其他情况 |

步数越少，分数越高。
