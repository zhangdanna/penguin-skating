### 4. 微信分享增强 (wechat-service.js)

#### 新增功能

| 功能 | 说明 |
|------|------|
| 分享奖励 | 分享成功获得5🐟 |
| 冷却机制 | 60秒冷却时间 |
| 冷却提示 | 显示剩余冷却时间 |
| 分享回调 | 触发成就记录 |

#### 分享流程

```
用户点击分享
    ↓
检查冷却时间
    ↓
┌─ 冷却中 → 提示剩余时间
└─ 可分享 → 打开分享界面
              ↓
         分享成功
              ↓
         发放奖励（5🐟）
              ↓
         记录分享次数
              ↓
         检查成就解锁
```

#### 主要方法

| 方法 | 说明 |
|------|------|
| `share()` | 主动分享（带奖励） |
| `setShareRewardCallback(callback)` | 设置分享奖励回调 |
| `canShare()` | 检查是否可分享 |
| `getShareCooldownRemaining()` | 获取冷却剩余时间 |

## 数据流

### 成就解锁流程

```
游戏事件（通关/分享/等）
    ↓
记录统计数据
    ↓
检查成就条件
    ↓
┌─ 满足条件 → 解锁成就
│              ↓
│           显示通知
│              ↓
│           发放奖励
│              ↓
│           保存数据
└─ 不满足 → 继续游戏
```

### 分享奖励流程

```
用户点击分享
    ↓
检查冷却（60秒）
    ↓
┌─ 冷却中 → 显示提示
└─ 可分享 → 调用微信分享API
              ↓
         ┌─ 分享成功 → 发放5🐟
         │              ↓
         │           记录分享次数
         │              ↓
         │           检查成就
         └─ 分享取消 → 无奖励
```
