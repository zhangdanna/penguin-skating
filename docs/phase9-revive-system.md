# 企鹅滑冰 - 第九阶段：复活机制

- 复活选择UI界面

#### 复活方式

| 方式 | 每日次数 | 条件 |

#### 复活效果

| 效果 | 说明 |
|------|------|
| 位置恢复 | 企鹅回到掉入冰窟窿前的位置 |
| 冰块保留 | 已推动的冰块位置不变 |
| 步数+5 | 复活后增加5步惩罚 |
| 每关限1次 | 同一关卡只能复活1次 |

#### 主要方法

| 方法 | 说明 |
|------|------|
| `canRevive(type)` | 检查是否可以复活 |
| `getRemainingCount(type)` | 获取剩余次数 |
| `hasEnoughFood(foodManager)` | 检查食物是否足够 |
| `revive(type, foodManager)` | 执行复活 |
| `savePosition(penguin, stones)` | 保存位置 |
| `resetLevelRevive()` | 重置关卡复活状态 |
| `getStatus()` | 获取复活状态 |

### 3. 游戏主逻辑更新 (game.js)

#### 失败处理流程

```javascript
onFail(reason) {
  // 1. 保存当前位置
  this.reviveManager.savePosition(this.penguin, this.stones)

  // 2. 检查是否可以复活
  const canRevive = !status.currentLevelRevived && (
    status.remaining.shareFriend > 0 ||
    status.remaining.shareGroup > 0 ||
    status.remaining.watchAd > 0 ||
    this.reviveManager.hasEnoughFood(this.foodManager)
  )

  // 3. 显示复活界面或自动重启
  if (canRevive) {
    this.reviveScene.show()
  } else {
    setTimeout(() => this.restartLevel(), 2000)
  }
}
```

#### 复活成功处理

```javascript
onReviveSuccess(result) {
  // 1. 恢复企鹅位置
  this.penguin.x = result.lastPosition.x
  this.penguin.y = result.lastPosition.y

  // 2. 恢复冰块位置
  result.lastStones.forEach((stoneState, index) => {
    this.stones[index].x = stoneState.x
    this.stones[index].y = stoneState.y
  })

  // 3. 增加步数惩罚
  this.moves += result.movePenalty

  // 4. 恢复游戏状态
  this.gameState = 'playing'
}
```

## 数据流

### 复活流程

```
企鹅掉入冰窟窿
    ↓

    ↓
┌─ 可复活 → 显示复活选择界面
```

## 平衡性设计

| 设计点 | 说明 |
|--------|------|
| 每关限1次 | 防止无限复活，保持挑战性 |
| 步数+5 | 复活有代价，影响星级评价 |
| 每日次数限制 | 防止过度依赖复活 |
| 食物消耗 | 提供无限制复活选项，但消耗资源 |
